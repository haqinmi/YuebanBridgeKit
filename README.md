# ★★ YuebanBridgeKit —— 月伴的**通用桥骨架**

> ★ 一句话：★★ **桥是一个客户端** ✓ —— ★ 它为**任意一个世界**做五件事 ✓：
> ★ **上线报能力 · 上行只传结论 · 收 op 回执 · 离线队列 · 读口** ✓
>
> ★★ **换一个世界 = 只改一个适配文件** ✗ —— ★ 那是"通用"的判据 ✓

---

## ★ 它是什么 / 不是什么

| ★ 是 ✓ | ⛔ 不是 ✗ |
|---|---|
| ★ 一个**客户端**跑的东西（★ 与那个游戏同一台机器 ✓） | ★ 平台的一部分 ✗ |
| ★ 一个**骨架**（★ 世界无关的那一半 ✓） | ★ 一个新的并列概念 ✗ |
| ★ 一条**上网的线**（★ 拉，⛔ 不是推 ✗） | ★ 一个客户端**界面** ✗（★ 界面是另一件事 ✓） |

★ **桥接在客户端，不接在服务器**（★ 三条理由 ✓）：
1. ★★ **原始流永不出端** ✗ —— ★ 桥要读的东西只在本机 ✓
2. ★★ **平台一重启，桥全断** ✗ —— ★ 2026-10-08 实拍过一次 ✓
3. ★★ **外面按什么写** ⇒ ★ **平台得先出接口这个承诺** ✓

# ② 改三处：platform / character_id / source

## ★★★ 写一个新世界：就实现三个方法

```python
# yueban_bridge/adapters/my_game.py
from ..world import BaseWorld, Event, Op, OpResult

class MyWorld(BaseWorld):
    name = "my_game"

    def capabilities(self):
        # ★ 如实报 ✗ —— ★ 报了她能做的就必须能做 ✓
        #   否则她会说"我画给你看"，而画不出来（最伤沉浸的那种错 ✓）
        return {"say": True, "emote": ["soft"], "read": ["chat"], "draw": False}

    def poll(self):
        # ★★ 只给**结论**、而且**只给新的** ✗
        #   · 结论 = 一句话 / 一个标签 / 一条事件 ✓（⛔ 不给原始日志 ✗）
        #   · local_id 必须**稳定**（★ 重发幂等的地基 ✓ ⛔ 别用当前时间 ✗）
        return [Event(kind="speak", local_id="my:1042",
                      data={"text": "我回来了"})]

    def apply(self, op: Op) -> OpResult:
        # ★ 做不了**也要回执** ✗
        return OpResult(id=op.id, ok=False, note="这个世界没有这个能力")
```

★ 然后清单里 `"entry": "yueban_bridge.adapters.my_game:MyWorld"` ✓
★★ **骨架别处一个字都不用改** ✓ —— ★ 要改 ⇒ ★ **那就不叫通用** ✗

## ★★★ 一条**最容易搞错的**：队列不是记忆

★★ **本地端不做记忆** ✗ —— ★ 那是《设计-本地端与服务器》的**唯一纪律** ✓
★★ 但★ **"还没送出去的结论"不是记忆** ✓：

| ★ 队列 ✓ | ⛔ 第二份记忆 ✗ |
|---|---|
| ★ 只存**还没送到的** ✓ | ★ 存"她说过什么"当第二份真源 ✗ |
| ★ **送到即删** ✓ | ★ 留着、还能查 ✗ |
| ★ **不参与回忆** ✗ | ★ 参与回忆 ✗ |

★ 所以它**不违反**那条纪律 ✓ —— ★ 它是"**快递站**"，⛔ 不是"**仓库**" ✗
★ 但★ 名字要叫 `pending_events` ✗ —— ★ 实测：旧客户端那张表叫 `pending_memories`，
★ 读的人**会以为它在存记忆** ✓
